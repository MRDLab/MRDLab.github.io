Logos for the Commercialization page.

| File | Company |
|---|---|

**Both are white-on-transparent versions**, taken from each company's own
site where they sit on dark backgrounds. That is why the logo plates on
this page are dark rather than white like the home page's collaborator
strip — a white plate would render them invisible.

If you obtain dark/positive versions, swap the files and change
`class="logo dark"` to `class="logo"` in `commercialization.html`.

As with partner logos elsewhere: these are the companies' trademarks.
The lab's PI co-founded both, so permission should be straightforward,
but it is worth confirming.
